# Predictive Maintenance ML Model

This project focuses on predicting equipment failure before it happens using machine learning.
The goal is to reduce downtime and maintenance cost by detecting early warning signs in sensor data.

## What this project does
- Loads time-series sensor data (vibration, temperature, pressure)
- Generates rolling statistical features
- Trains a machine learning model to predict failure events
- Saves trained models for reuse

## Why it matters
Predictive maintenance is widely used in industrial engineering.
This project reflects my background in mechanical systems, data analysis, and applied machine learning.

## Tools used
- Python
- Pandas, NumPy
- Scikit-learn
- Joblib
